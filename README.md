# AivisSpeech 読み上げ Chrome拡張機能

選択したテキストを右クリック → 「読み上げ」で [AivisSpeech Engine](https://aivis-project.com/) に音声合成させ、その場で再生する Chrome 拡張機能です。

## 機能

- テキスト選択 → 右クリック → 「読み上げ」で即再生
- 長文は文単位に分割し、生成しながら再生するパイプライン処理
- 生成中 / 再生中 / 進捗（N/総数）をページ右下のトーストとアイコンバッジで表示
- トースト右の ✕ ボタンで即時停止
- 設定画面から音量を調整可能（0〜200%、ブラウザ再起動後も保持）

## 前提条件

- AivisSpeech Engine が起動していること
- ファイアウォールでポート `10101` が開放されていること

## インストール

1. このリポジトリをクローン（または ZIP ダウンロード・展開）
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダを選択

## 設定

`chrome://extensions` → 拡張機能の「詳細」→「拡張機能のオプション」から音量を調整できます。

## ファイル構成

```
manifest.json      # 拡張機能の設定
background.js      # Service Worker（音声生成・パイプライン制御）
options.html       # 設定画面
options.js         # 設定の保存・読み込み
icons/             # アイコン画像
```

## API 設定

`background.js` の先頭2行でサーバーアドレスと話者 ID を変更できます。

```js
const SPEAKER_ID = 888753763; // まお・おちつき
const API_BASE = 'http://192.168.11.150:10101';
```
